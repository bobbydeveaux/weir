# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on this repository, go to **Security**, then **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it.

You will get an acknowledgement, and we will tell you what we plan to do and when.

## Supported versions

Weir has no released version yet. Once `v0.1.0` is tagged, this page will list which versions receive fixes.
